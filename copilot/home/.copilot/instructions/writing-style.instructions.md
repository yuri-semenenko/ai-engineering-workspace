# Writing Style

Write concise, direct, natural technical prose.

Prefer:

- concrete claims
- active voice
- short paragraphs
- specific trade-offs
- explicit assumptions
- plain English for PR reviews and GitHub markdown

Avoid:

- marketing phrasing
- inflated significance
- generic AI-sounding prose
- excessive hedging
- em dashes
- arrows and decorative symbols
- "it is not just X, it is Y" constructions
- vague authorities like "experts say" without a source

For PR comments, make the comment useful to the author:

- state the problem
- explain the impact
- suggest the smallest reasonable fix
